## 概要

エージェントに運用の文脈を与え、障害調査と対処の優先順位付けを支援します。監視情報を増やすだけでなく、依存関係と業務への影響をエージェントが扱える形に整理する発表です。

## 主な発表

- Azure Monitor Health models はテレメトリからリアルタイムのヘルスグラフを作り、アプリ構成、依存関係、業務の優先事項をつなぎます。
- Azure Copilot Spaces と Custom skills は組織の運用の文脈を保持。Azure Workload Center で Oracle と SAP の状態監視や構成確認を拡張します。
- SRE Agent は顧客管理キー、Entra Agent ID・Agent 365 連携、エージェント間の情報とタスク共有、Teams 連携、マルチクラウド調査を追加します。

## 提供状況・注意点

Monitor の自然言語機能と Health models は GA。Spaces、Custom skills、Workload Center の今回の拡張、SRE Agent の上記新機能は Preview。利用するデータの範囲、実行権限、承認境界を個別に確認します。
