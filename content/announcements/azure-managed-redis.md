## 概要

Redis のデータ型と検索機能をまとめ、AI アプリの開発時に接続設定を確認する支援を追加します。

## 主な発表

- Redis 8 は JSON、検索、時系列、ベクトルなどを統合したバージョンとして Azure Managed Redis に追加されます。
- 類似した要求への応答再利用や、エージェントのメモリ・文脈を保持する用途を想定しています。
- Agent kit はアプリが Redis をどう使うかを確認し、信頼性、ネットワーク、性能へ影響する設定の変更候補を開発者へ提案します。

## 提供状況・注意点

Redis 8 と Agent kit はともに Preview。既存の Managed Redis で利用するエンジンや機能の互換性、変更提案の内容を確認してから適用してください。
