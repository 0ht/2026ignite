## 概要

人とエージェントの ID、端末、ネットワークへのアクセスを整理し、エージェントの行為を人の操作と区別して管理する拡張です。

## 主な発表

- GitHub Copilot CLI と Claude Code から始めるローカルエージェントの Agent ID、および Autopilot のクラウドエージェント ID を拡張します。
- Microsoft MCP Server for Enterprise は権限に沿った Entra データのアクセスを提供。Global Secure Access はエージェントの通信を把握し、MCP のツール、リソース、プロンプトなどの制御を追加します。
- 条件付きアクセスのポリシー計画、強い資格情報、テナント横断の構成管理、Backup and Recovery Premium などで ID 基盤を強化します。

## 提供状況・注意点

Microsoft MCP Server for Enterprise と Agentic traffic acquisition は GA。上記の新しい Agent ID、MCP Firewall、ローカルエージェントのネットワーク制御、ポリシー計画や復旧の拡張は Preview。

今回発表した追加機能の提供段階を記載しています。既存機能の状況、対象ライセンス、エージェントの対応範囲は個別に確認してください。
