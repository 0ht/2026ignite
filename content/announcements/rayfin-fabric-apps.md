## 概要

生成した画面を本番アプリへ進めるために、データベース、認証、データ API、ガバナンスをまとめる発表です。分析結果を読むだけでなく、入力や承認などの操作へつなげます。

## 主な発表

- Rayfin と Fabric apps は SQL database や Fabric HorizonDB、既存のセマンティックモデル、Warehouse、Lakehouse と接続します。
- OneLake Governance hub の一元管理、セキュリティ制御、組み込みの可観測性を追加。Copilot Managed Runtime とも接続します。
- Power BI Desktop では自然言語と管理されたセマンティックモデルを使い、入力・更新・データソースへの書き戻しを備えるアプリを構築します。

## 提供状況・注意点

Book of News は Rayfin と Fabric apps を GA、Power BI Pro 向けのデータアプリ作成を Preview としています。Fabric HorizonDB も Preview です。

Microsoft IQ の総合ブログには Fabric apps の対話機能を Preview とする記載があります。アプリ基盤、選ぶ DB、IQ の埋め込み、Power BI からの作成という個別の機能単位で確認してください。
