## 概要

Web IQ は Web、ニュース、画像、動画などの情報をエージェントとアプリへ供給します。組織内部の文脈を担う IQ と組み合わせ、外部の情報を根拠に回答します。

## 主な発表

- Auto は Web、Images、Videos、News、Places、Weather をまとめて扱います。Auto Advanced は結果を評価し、必要に応じてクエリを修正して再検索します。
- Scopes は URL、ドメイン、サイト、パスを含める・除外する設定を提供します。
- Places と Weather を追加。Commerce は商品 ID、価格、在庫、複数販売者の情報などを構造化して提供する計画です。

## 提供状況・注意点

Web IQ、Auto、Auto Advanced、Scopes、Places、Weather は GA。Commerce は Private Preview。

公式ブログは全 Azure 顧客が待機リストなしで開始できると説明しています。利用料金、対応する情報種別、提供地域、コンテンツの利用条件は導入時に確認してください。
