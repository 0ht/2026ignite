## 概要

既存の Windows ベースの業務を支える基盤を強化し、企業が管理するインフラで AI 推論を実行する方向へ拡張します。

## 主な発表

- 堅牢化した Server Core、セキュリティベースライン、Trusted Launch、耐量子暗号、自動証明書管理を発表しました。
- NVMe over Fabrics、ネイティブ NVMe、ReFS からの起動でストレージ関連の機能を拡張します。
- Intune、Azure Arc、Windows Admin Center、vMode での管理に加え、Windows ML、Foundry Local、vLLM、Llama.cpp やアクセラレーターを使う推論構成を示しました。

## 提供状況・注意点

セキュリティ、性能、管理の機能は Windows Server Insider Program の Preview。Hybrid intelligence は限定された顧客向けの早期アクセスで、ハードウェア要件があります。正式導入の判断はサポート条件と各機能の提供段階を確認してください。
