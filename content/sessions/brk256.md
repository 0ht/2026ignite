## 概要

Foundry と fal の連携を通じ、画像・動画生成モデルの選択からクリエイティブ制作、本番利用までを紹介します。

## 内容の要約

Microsoft Foundry のモデル群と fal の生成メディア基盤を組み合わせ、テキストだけでなく画像・動画・音声をつないだ制作フローを企業が本番利用する方法を紹介します。冒頭では、Foundry 上のモデル選択肢と、HyperCinema の来場者向け個別映像、WPP の広告案、Pixel Lab の Coldplay ファン向け動画リミックス、CoStar の音声検索といった顧客事例を振り返ります。これらを、単一の動画モデルではなく、複数の専門モデルを工程ごとに使い分けるマルチモーダル制作へ広げる構成です。

発表の中心は「fal on Microsoft Foundry」です。スライドは fal の動画モデル群を Foundry Models からファーストパーティの Azure サービスとして利用できる Public Preview と表記しています。新モデルとして Kling Video v3 の Pro／Standard／Turbo、MiniMax H3 Max／Turbo、LTX-2.5 Pro／Fast を挙げます。対談では、Kling は高品質・高解像度の映像向けで Pro ほど品質重視、Turbo ほど速度・コスト重視、MiniMax H3 は速度とオープン性を生かした高頻度生成や調整、LTX は映像の各要素や動きを制御したい制作向けと、モデル選択の観点を説明します。Kling などの動画モデルを米国内でホストすることにも触れています。

デモはモデルごとの短い生成映像から始まり、MiniMax H3 Turbo によるファッション撮影、Kling の蛍が舞う夜の森、H3 Max による音声付き対話、LTX によるブライダル映像を例示します。Foundry ポータルでは LTX-2.5 Pro に電車の映像を生成させ、API／ポータルからのデプロイを紹介します。続いて MAI Image 2.7 で人物写真の服装・背景を編集して動画化するフロー、研修テキストを LLM で画像・動画用プロンプトへ展開して安全教育映像にする流れ、スケッチ・色見本・参照画像から車の広告素材を作成し、縦横比や言語を変えて各媒体用に展開する例を実演します。画像と動画のモデルを順につなぎ、試作から大量生成へ進めるのが具体的な主題です。

まとめでは、評価指標だけで一律にモデルを選ぶのではなく、同じプロンプトを複数モデルに適用して表現・動き・品質を比較し、ユースケースに合うものを選ぶよう勧めています。制作時の探索だけでなく、Foundry の統制、ホスティング、デプロイ経路を通して本番に移す点が結論です。

## 提供状況

スライドは fal on Microsoft Foundry と新しい fal 動画モデルを Public Preview と明記しています。デプロイには Azure サブスクリプションでの fal 機能有効化／同意が必要とデモで説明されています。したがって、動画での生成実演は一般提供の証拠ではありません。利用可能なモデル、リージョン、価格・性能は更新され得るため、現行の提供情報は公式リンクで確認してください。
