## 概要

Copilot Studio のアプリ、ワークフロー、エージェントを共通のセキュリティと管理基盤の上で組み合わせる方法を紹介します。

## セッションの要点

### 業務プロセスを一体で設計する

スライドでは、自然言語による対話からエージェント、ワークフロー、アプリを作成・改善し、それぞれを組み合わせて業務プロセス全体を構築する構想が示されました。エージェントの判断、ワークフローによる手順、アプリを介した人の作業を一つのソリューションとして扱います。

複雑で長時間の業務には Microsoft Copilot harness、音声・顧客対応には Customer conversation harness を挙げ、既存の Standard harness も選択肢として示しています。Copilot harness については、反復的な実行、コネクタや MCP の呼び出し、ファイルや大量データの処理、管理されたサンドボックスを紹介しています。

### アプリの実行と管理

Copilot Managed Runtime は、Copilot Studio、Copilot Code、Copilot Cowork や対応する外部ツールで作ったアプリを Microsoft 管理の環境で実行する基盤です。コネクタや Work IQ を介した業務データ接続に加え、ID、アクセス、共有、利用状況、クレジット消費を管理する構成が示されました。スライドは **2026年11月17日から一般提供**と記載しています。

管理者が設定するコネクタ方針やデータ境界、ゲストを含む共有制御、Entra 認証や条件付きアクセスを組み合わせ、作成時から管理することを重視しています。

### デモ：新入社員のオンボーディング

新入社員向けエージェントに入社案内や福利厚生の資料を与え、質問への回答と初週の予定表作成を実演しました。共有メールボックスに届いたメールを分類し、新入社員の情報抽出や Excel への記録につなぐワークフローも示しました。

別のデモでは、オンボーディングアプリからタスクをエージェントに委任し、状況に応じた提案を受け取ります。アプリの作成と公開は管理されたランタイムで行い、管理者が接続先や共有状況を確認する流れです。

### 発表時点のプレビュー

- **Copilot Managed Runtime と Copilot Studio の連携**：エージェントやワークフローをローカルで作成し、Git ベースのソース管理を使って公開する機能はパブリックプレビュー。
- **コードベースのエージェント**：選択したモデルやハーネスを使うエージェントを Managed Runtime で動かす機能は早期アクセスプレビュー。
- **Fabric 連携**：永続データや追加のバックエンドを必要とするアプリに、Fabric のデータベース・ストレージ・API を利用する連携は Frontier Preview。
- **Answer with UI**：会話内で MCP アプリのインタラクティブな画面を利用する機能は2026年11月のパブリックプレビューとして記載。

提供範囲や条件は発表後に変わる可能性があるため、導入時に公式情報を確認してください。
