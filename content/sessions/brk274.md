## 概要

VS Code のエディターと Agents ウィンドウを行き来し、人が編集・レビューする作業とエージェントへの委任を組み合わせます。

- Agent Host Protocol（AHP）では実行中のセッション、ツール操作、承認をホスト側で保持し、VS Code の各ビューや Copilot アプリ／モバイルなどの対応クライアントで同じ作業を引き継ぐ構想を説明します。
- **デモ:** Blobby の性格診断サイトを題材に、Autopilot と権限モードを選んで作業を開始し、Agents ウィンドウに移動。モデル比較では複数の実行を並列化し、判定役が結果を比較します。比較結果は課題や評価基準に依存します。
- 統合ブラウザーを共有してエージェントにクイズを操作させ、ページ上の要素を選んで HTML／CSS のコンテキストを渡します。カンバンの Canvas、実装前の HTML モック、画像生成も紹介します。
- 変更をファイル単位・差分単位で確認し、PR の作成、チェックやレビューの確認、Agent merge を同じウィンドウで扱う流れを実演。最初の PR 作成は失敗し、別の実例に切り替えています。
- 画像生成は当時のデモでは選択した会話モデルにかかわらず特定の画像モデルに委任し、画像モデルの選択は将来の予定と説明。機能は変化が速く、個別の提供段階はセッションでは明示されていません。
