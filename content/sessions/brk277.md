## 概要

Microsoft Copilot SDK 2.0 と参照実装を使い、社員向けアシスタントを安全性・費用・並列性の要件に合わせて発展させます。

- SDK はランタイムのプログラム用インターフェースで、ハーネスはその既定のエージェント構成。2.0 のマルチテナント対応により、共有プロセスで複数セッションを動かし、必要に応じて隔離環境を使えます。
- **デモ:** 会議リードの表を処理するアシスタントを構築。共有ランタイムで危険なホストツールを有効にすると他ユーザーのセッションファイルを読める問題を示し、セッションごとのコンテナーに変更します。この危険な設定は問題を示すための例です。
- 対話は共有環境で開始し、ファイルやシェルが必要なときだけコンテナーへ移す「promotable」、エージェントの状態を共有側に残しツールだけを一時コンテナーで実行する「direct」、独立したワーカーへ委任する「delegate」を比較。前者は昇格後もコンテナーが残るため、費用問題を先送りするだけです。
- 複数ファイルを並列処理するデモはワーカー起動に失敗し、再試行後も1ワーカーのみ起動。説明された複数並列の動作を当日の実演で確認できたわけではありません。スライドの費用グラフは実績ではなく例示です。
- 旧 GitHub Copilot SDK を Microsoft Copilot SDK と改称し、2.0 を前日にリリースしたと説明。Managed Copilot SDK は自社環境に配置・改造できるオープンソースの**参照実装**で、完成済みのマネージドサービスと同義ではありません。
