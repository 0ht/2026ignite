## 概要

GitHub Advanced Security を使い、生成コードの検査、既存コードの発見、エージェントによる修正、ルールセットによる統制を開発フローに組み込む。

## 内容の要点

- **発見と修正**：CodeQL の決定的な静的解析と AI scan を併用する。後者は CodeQL 対応外の言語にも対象を広げるが、AI の結果は非決定的である。Agentic Autofix は最大25件のアラートを Copilot に割り当て、修正と検証を経てレビュー用 PR を作る。
- **デモ：統制から修正まで**：push ルールで拡張子・サイズを制限し、branch ルールで重要度に応じた code scanning、secret scanning、ライセンス等のチェックを要求。COBOL／Java／シェルを含む移行リポジトリで PR の検出結果を確認し、COBOL の OS コマンドインジェクションを Copilot に修正させ、人が PR を確認する。
- **制約と当時の提供状態**：デモの新しい PR 画面はプレビュー。Emdash 技術を使う GitHub の deep scan はプライベートプレビューで、通常の Emdash 製品より操作の自由度と実行時間が限られ、講演では最大30分と説明。Code Security と Secret Protection は別々の追加ライセンス。既存の SAST／SCA 製品の代替か補完かは要件次第である。
