## 概要

Visual Studio の配布・更新、拡張機能、Copilot のモデルとエージェント操作を企業で管理する方法を説明する。

## 内容の要点

- **配布と更新**：承認済みの full layout を共通の配布元にし、各チームの `.vsconfig` で必要な workload を選ぶ。標準ユーザー制御を Intune／Group Policy で配布し、管理者権限を与えずインストール・更新を可能にする。登壇者のテストでは full layout の初回取得に約30分・86 GB を要した。
- **拡張機能デモ**：private marketplace の接続先を設定し、社内拡張と public marketplace の upstream、発行元・ID・バージョンによる許可を示す。閲覧制御だけでは直接配布ファイルを防げないため、インストール時の制御や VSIX の来歴確認、実行時の監査・ロード制御も検討している。
- **AI 管理デモ**：GitHub Copilot、BYOK、組織内またはローカル推論という選択肢を紹介。managed settings で bypass permissions を禁止した Insider ビルドでは、対話型の agent mode は残しつつ allow all／autopilot を無効にした。モデル選択、MCP registry、カスタム指示も説明し、指示は強制ではなくガイダンスと明言。
- **発表当時の状態**：private marketplace はプレビュー、Entra 認証は未リリース。Visual Studio の managed settings 対応は開発中で、クライアントとビルドによって利用できる制御は異なる。sandboxing、プラグイン管理、GitHub 管理の BYOK は今後の投資項目。
