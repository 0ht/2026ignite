## 概要

GitHub Enterprise の AI ガバナンスを、全社の基本方針、チーム別の権限、クライアント設定、利用状況の観察で組み立てる。

## 内容の要点

- **既定と例外**：未設定の GA 機能・クライアントにはグローバル既定を適用し、個別の明示的な設定は維持。プレビュー機能は自動有効化の対象外。モデルにも既定を設定できるが open-weight モデルは自動有効化から除外される。
- **デモ**：enterprise teams mode で、全社には無効なモデルを特定チームに追加許可。複数チームの許可は合算され、全社で明示的に有効・無効にした決定はチームから上書きできない。Fusion に使わせるモデルを、開発者が直接選べるモデルとは別に絞る例も示した。
- **managed settings**：Git で管理する JSON を使い、デフォルトモデル、許可・拒否する MCP、plugin marketplace、サンドボックス等を設定し、許可された項目をチームごとに調整する。MCP の deny は allow に優先し、許可だけではインストールや認証はされない。対応はクライアントごとに異なる。
- **発表当時の状態**：enterprise teams によるモデル管理と agent session streaming は public preview。組織チームの client customization、利用データからのポリシー推奨、予算到達時の安価なモデルへの切替、モデル提供元や分類での一括管理は今後の方向性として紹介された。
