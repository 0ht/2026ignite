## 概要

エージェント向け検索としての Web IQ を紹介し、最新の Web 情報を使って回答の根拠を補う考え方を説明します。

## セッションの内容

Web IQ は、エージェントが外部の情報を取得して回答の根拠に使うための検索サービスです。発表者は、品質、情報の鮮度、応答速度、トークン効率を評価軸に挙げ、発行元によるコンテンツ利用の制御や、企業向けのデータ保護にも言及しました。

### 検索と構造化データ

公開 Web に加え、ライセンスを持ち込むデータや、場所・天気・商取引の構造化情報を扱う方向性を紹介しました。場所と天気は発表時点で一般提供、商取引はプライベートプレビューです。たとえば店舗の営業時間と天気予報を組み合わせ、訪問先を検討する用途を示しました。

医療情報の例では、検索結果の権威性に関するシグナルを利用し、対象の読者に応じて検索対象ドメインを含めたり除外したりする方法を説明しました。情報源の選択は、回答の正確性や医療判断を保証するものではなく、個別の確認が必要です。

### Web IQ Auto のデモ

複数の条件を含む質問を一度の呼び出しで分解し、Web、場所、天気などの根拠をまとめて返す Web IQ Auto を紹介しました。シアトルの顧客訪問に向けて喫茶店と天気を調べる比較デモでは、個別ツールを使う構成と比べ、トークン使用量、応答時間、モデル費用が減ったと説明しています。数値はこのデモの条件での比較です。

### 顧客事例

Northern Trust は、公開情報と社内の顧客情報を組み合わせて見込み客を並列調査し、人が優先順位や適合性を判断する事例を紹介しました。Genspark は音声エージェントの応答速度、Cloudforce は教育向けサービスでの検索とトークン効率について、それぞれ自社環境での結果を説明しました。
