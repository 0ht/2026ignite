## 概要

Microsoft Perception のエージェント構成、侵入テスト、SOC 向け自動化、外部連携と今後の方向性を紹介します。

## セッションの内容

Microsoft Perception の一般提供開始と今後の方向性を紹介します。事前に攻撃経路を調べるレッド、インシデントの調査と検知を担うブルー、修復を支援するグリーンの各エージェントを、プレイブックで連携させる構成です。

### Web アプリの検証

デモでは DNS によって所有権を確認した対象を選び、認証情報や MDASH のコード検査結果を設定します。エージェントの作成した計画を承認して検証を実行し、悪用可能性の根拠や推奨する軽減策をレポートで確認しました。認証方法の拡充や修復フローの改善は今後の方向性として紹介されています。

### 脅威情報から検知を作成

外部の記事を入力し、脅威情報エージェントが攻撃手法や指標を抽出します。検知作成エージェントはその結果から組織向けの検知候補を作り、過去のデータで試してノイズを評価します。提案されたクエリは担当者が確認・調整できます。

### 連携と人による管理

発表時点で Sentinel 経由の AWS、Okta、Salesforce のデータを対象にした分析を紹介しました。API と MCP を使って既存の運用画面から利用する例も示しています。エージェントには個別の ID と権限を設定し、実行履歴を確認できる設計です。

利用企業の登壇者は、調査時間の短縮や医療現場での判断の重要性を共有しました。数値は各社の環境における報告として受け止める必要があります。
