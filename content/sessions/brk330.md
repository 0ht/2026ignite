## 概要

アプリ、クラウド、実行環境、ネットワークにまたがる攻撃経路を、Defender や Azure の保護機能で検出・阻止します。

## セッションの内容

アプリのコードからクラウド、実行環境、ネットワークまでのつながりを見て、攻撃の各段階で介入する方法を説明します。AI アプリもモデルだけでなく、依存するコンピュート、ID、データの保護が必要です。

### 攻撃経路と実行時の調査

Defender のデモでは、インターネットに公開されたサーバーの脆弱性と、管理 ID を経由して Azure OpenAI リソースへ到達する経路を確認しました。同じサーバーを SOC のインシデントからも調べ、ネットワークとプロセスの証拠を関連付けます。セキュリティ管理者と SOC が同じ資産の異なる側面を確認する流れです。

### ネットワークでの追加保護

Azure Adaptive Virtual Patching は、脆弱性に応じた一時的な軽減策を適用して、パッチ展開までの時間を確保する仕組みとして紹介されました。デモでは管理者が軽減策を承認し、恒久的なパッチの適用後に戻す流れを示しています。発表時点ではパブリックプレビューです。

Azure Firewall の AI Security アドオンについて、プロンプトインジェクション対策、Purview と連携したネットワーク DLP、ファイルやアプリへの攻撃のインライン検査をデモしました。Azure Bastion の録画・コマンドログを分析し、リスクのある操作と元の証拠を関連付ける機能も紹介されました。これらは発表時点でプレビューです。
