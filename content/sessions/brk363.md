## 概要

分散したデータベースの把握や管理を支援する Database Hub とデータベースエージェントの構想を紹介します。

## セッションの内容

### Database Hub で資産を把握

Fabric の Database Hub を使い、Azure SQL、SQL Server、PostgreSQL、Cosmos DB などの資産とセキュリティ、性能、最適化の情報をまとめて確認します。オンプレミスや他クラウドの SQL Server は Azure Arc の有効化が必要です。既存の Azure RBAC に基づき、利用者に権限のある対象が表示されます。

デモでは管理ポータルで Hub を有効化し、タグで本番の重要サーバーに絞り込んだビューを保存・共有しました。公開ネットワークへの露出やリソース不足などを調べ、診断クエリを対象サーバーのコンテキストとともに SSMS に渡す例も示しました。

### エージェントによる検知と調査

プレビューの database agent はテナント設定と対象データベースの性能監視を有効にして利用します。ブロッキング、長時間クエリ、実行計画の悪化、CPU・メモリ・I/O の問題などを検出し、関連クエリや調査の記録を提示します。発表時点の Hub 内エージェントの対象は Azure SQL と Hyperscale が中心で、対象拡大は計画中と説明しました。

Copilot に問題の原因や推奨事項を尋ね、クエリの書き換え案を得るデモを実施しました。提案の意味や結果の同等性は DBA が検証します。VS Code の PostgreSQL 拡張ではインデックスの提案を承認・却下する例も紹介しました。自動修復、履歴の記憶や外部 IT 管理ツールとの連携は今後の構想として扱われています。
