## 概要

Dynamics 365 Customer Service と AI エージェントで問い合わせの自己解決、担当者支援、業務自動化を進める方法を示します。

## セッションの内容

### サービス担当者とエージェントを支える基盤

Alan Ross は、顧客サービスを「一度購入した顧客が再び選んでくれるかを左右する接点」と位置づけ、AIだけでなく担当者が使う基本機能も磨く方針を説明しました。デモでは Copilot Service Workspace の新しい画面で、Dataverse の情報を集めたケース全体像を確認し、ケースやメールへの対応を一画面で進めます。

顧客対応の自動化は、最初から全面移行するのでなく、少数のインテントから始めて対象を広げる進め方を紹介。Intent Insights は問い合わせの多い話題を並べ、新たなインテントや適用できるナレッジを見つける機能として示されました。Workforce Engagement Management（WEM）のデモでは、ケースや会話の評価を担当者別に集計し、上司がコーチングのコメントやナレッジ記事に結び付いた研修を割り当て、研修後の変化を追います。

### 音声対応と Microsoft Copilot のデモ

CX1 の音声機能を Copilot Service Workspace に組み合わせたデモでは、クレジットカード解約を希望する顧客との通話から、担当者に次の質問を提案し、請求先郵便番号と本人確認情報を収集しました。顧客が想定と違う順序で回答しても必要項目を追跡し、そろった情報を Power Automate コネクタ経由で API に渡してカード情報を取得します。手順を暗記させるのではなく、インテントの簡潔なプレイブックと業務システムへの接続で、画面を行き来せずに処理する流れを示したものです。

Microsoft Copilot の Service Agent では、MCP ツールを介して直近のケースをアプリ形式で表示し、その場で更新・並べ替えを行う例と、ケースからフィールドサービスの作業指示を作成して技術者の空き状況を調べる例を紹介しました。Cowork では過去60日分のケースを調べて傾向やチャネルをまとめた PowerPoint を作るシナリオ、Autopilot では選択中の音声出力先を直し、対応記録として IT ケースを作るシナリオを示しました。

### BNY の取り組み

BNY の Christian Lewis は、同行の社内 AI 基盤 ELIZA を、社内データやツール、エージェントを権限・ガバナンスのもとで利用する仕組みとして説明しました。Dynamics 365 を営業・サービスに限らず使う同行の経験を踏まえ、Teams の会話、Copilot、Dynamics の顧客情報をつなぎ、会議後の要約やタスク、顧客へのフォローアップを支援することで、従業員が顧客対応に使える時間を増やす考え方を共有しました。これは顧客側の取り組み紹介であり、製品デモで示した全機能が BNY で稼働しているという説明ではありません。
