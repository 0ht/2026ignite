## 概要

Azure の AI 基盤について、冷却、シリコン、ストレージ、ネットワーク、推論実行、機密コンピューティングを概観します。

## セッションの内容

- **データセンターと計算基盤:** 空冷設備と液冷 GPU を別の温度帯で冷やすゾーナル冷却を紹介し、GPU 側は最大 45°C の液体を使えると説明。さらに、シリコン上に冷却流路を刻むマイクロ流体冷却を試験中の技術として示しました。Maia 300 では、最大 128 ラック・12,288 アクセラレーターの Superpod と、アクセラレーター間の低遅延接続を扱い、AI を使って演算カーネルを融合・最適化した事例も紹介しています。
- **ストレージと稼働率:** Azure Boost の RDMA で Blob Storage から VM／GPU メモリへデータを直接転送し、CPU のコピー負荷を下げる構成を実演。大きな Blob では CPU 使用量を最大 43 倍抑えられるというスライド上の測定値も示されました。AKS の複数 GPU ノード間で NVMe キャッシュを共有する DACS、計算資源を優先度別にまとめて空きを再配分する Manifold も説明しました。
- **エージェント実行:** 会話の KV キャッシュを Azure Storage に退避・再利用する Context Cache Technology、Hyper-V 分離を維持しつつ bare metal 上で動かす ACI の AI サンドボックスを紹介。スナップショットからの再開やリソース伸縮に加え、デモでは 10,000 個のサンドボックスを立ち上げ、P50 起動時間 2 秒を報告しました。
- **エージェントの保護:** Agent Grid はサンドボックス外のネットワーク制御点で接続先や MCP ツールへのアクセスを監視・制限し、監査情報も残します。さらに、機密性と信頼性のラベルをコンテキストからツール呼び出しまで伝播させる Information Flow Control を紹介し、情報流出を拒否したり、未信頼入力を含む操作を承認待ちにしたりする考え方を示しました。機密 GPU 上での推論デモも含まれます。
