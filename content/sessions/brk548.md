## 概要

Replit のエージェント実行、サンドボックス、ID、インフラと、企業向けアプリの安全な展開を紹介します。

## セッションの内容

- **Replit の位置づけ:** Replit をアプリ作成環境だけでなく、利用者が依頼した作業をクラウド上のエージェントが実行し、生成したアプリを企業環境へ展開する基盤として説明。講演者は、社内でも開発・レビューにエージェントを活用していると述べ、実演ではドキュメント修正をエージェントに依頼して Pull Request を作成させました。
- **分離された実行環境と委任 ID:** API サービスからセル型の分散基盤へ処理を振り分け、各エージェント作業には専用サンドボックスを割り当てます。ユーザーの権限をそのまま引き継がせず、権限を絞った委任トークンを使って、エージェントの操作をユーザーと個別のエージェント双方に帰属させる設計を説明しました。
- **耐障害性とアプリ展開:** エージェントの状態・進捗を永続化する実行サービスにより、再起動後も作業を回復でき、長期間のワークロードにも対応。サンドボックスはマイクロ VM として分離し、ファイル、ネットワーク、資格情報、リソース使用を制御します。完成したアプリは別のデプロイ制御プレーンとワークフローで公開します。
- **Azure テナントへの配置:** セル単位でデータ、状態、サンドボックス、アプリを顧客の Azure 環境に展開する Cloud Prem の構想を紹介し、マルチクラウドと単一テナントの選択肢を説明しました。これは講演時点で後日提供予定として語られており、提供済み機能とは区別が必要です。
