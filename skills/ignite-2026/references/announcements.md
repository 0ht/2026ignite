# アナウンス一覧

- [Agent 365 FinOps・Business Analytics](announcements/agent-365-finops.md) AI の利用額と成果を結び付ける FinOps 機能を拡張。Cost Management で消費の内訳、支出ポリシー、上限、アラートを管理し、Business Analytics で成功率や満足度などを確認します。Cost Management は Preview、Business Analytics は Frontier で提供し、12 月以降の拡張も予定しています。
- [Microsoft Agent 365](announcements/agent-365.md) エージェントの活動、用途、ツールを管理する機能を拡張。Microsoft 製・Microsoft 基盤上のエージェントの基礎的な利用状況と、プラグイン・スキル管理が一般提供となります。Dynamic Agent Risk、MCP ゲートウェイ連携、ローカル・シャドーエージェント管理は Preview。Action center は 12 月の Private Preview を予定します。
- [Azure Monitor・Copilot・SRE Agent](announcements/azure-agentic-operations.md) Azure Monitor の自然言語機能と Health models が一般提供となり、テレメトリを業務影響や依存関係と結び付けます。Azure Copilot の Spaces と Custom skills、Oracle・SAP の運用支援、SRE Agent の顧客管理キー、Agent ID、エージェント間連携、Teams・マルチクラウド対応は Preview で拡張します。
- [Azure AI 基盤・AKS](announcements/azure-ai-infrastructure.md) Foundry のオープンウェイトモデルやエージェントを自社の AKS クラスターへ展開する機能を Preview で発表。Agent Grid、VM レベルで隔離する Agent Sandbox、Azure 外のサーバーを使う Flex nodes も追加します。機密コンピューティングは複数 GPU、コンテナー、共同分析の保護を拡張します。
- [Azure Catalyst](announcements/azure-catalyst.md) インフラ、アプリ、データの調査から計画・移行・モダナイゼーションまでを Azure と GitHub でつなぐ Azure Catalyst が一般提供。Catalyst agent は旧 Azure Copilot migration agent を引き継ぎます。既存資産の把握とエージェントによる実行を接続し、より詳細な調査や統合移行シナリオを Preview で追加します。
- [Azure Chaos Studio](announcements/azure-chaos-studio.md) Workspaces と AKS 拡張が一般提供。可用性ゾーンの停止やデータベースのフェールオーバーなどの障害シナリオを再利用し、アプリの復旧能力を検証します。AKS 拡張は実験実行に必要な権限を減らし、Kubernetes Pod への制御された障害注入を支援します。
- [Azure Cobalt 200](announcements/azure-cobalt-200.md) Microsoft 製 Arm プロセッサを搭載する Cobalt 200 VM が一般提供。モデルの周辺で動く CPU 処理を対象に、Cobalt 100 比で最大 50% の性能向上を公表しました。一定速度とブーストのモード、大規模メモリ向け・ストレージ重視の VM を追加し、年末までに 24 リージョンへ展開する計画です。
- [Azure Cosmos DB](announcements/azure-cosmos-db.md) Shell、Rust SDK、Semantic reranker、全文検索のスコア取得、Azure Backup が一般提供。開発ツール、検索品質、独立したバックアップを強化します。VS Code 拡張の AI 支援データモデラーは Preview で、パーティションキーやコンテナー構成の設計を支援します。
- [Azure DocumentDB](announcements/azure-documentdb.md) VS Code 拡張と M10 から M30 の高速クラスター作成が一般提供。Azure Arc と Azure Local で MongoDB 互換ワークロードを実行する選択肢を Preview で追加します。DB・コレクション単位の細かな RBAC も Preview とし、配置先の制御と最小権限を強化します。
- [Azure HorizonDB](announcements/azure-horizondb.md) PostgreSQL 互換のマネージドデータベースが一般提供。Entra ID、Private Endpoint、マネージド ID、暗号化、複数ゾーンでの保護を組み合わせます。DB 内の AI モデル管理、SQL からモデルを呼ぶ AI Functions・AI Pipelines、Fabric へのミラーリングは Preview。Fabric HorizonDB とは提供形態と段階を区別します。
- [Azure Managed Redis](announcements/azure-managed-redis.md) Redis 8 と開発用 Agent kit を Preview で発表。JSON、検索、時系列、ベクトル検索などを一つの Redis バージョンで扱い、エージェントの文脈やメモリ、類似応答の再利用を支援します。Agent kit は接続、信頼性、ネットワーク、性能に関する設定を確認し、開発者へ改善候補を示します。
- [PostgreSQL on Azure](announcements/azure-postgresql.md) Oracle から PostgreSQL、Azure Database for PostgreSQL から HorizonDB への Azure DMS 移行支援を Preview で追加。Cobalt 200 と AMD v6 confidential compute、不変のポイントインタイム復元、同一ゾーンからゾーン冗長 HA への変更が一般提供。移行、性能、保護、回復性を機能ごとに拡張します。
- [Azure SQL](announcements/azure-sql.md) SQL Managed Instance の Next-gen General Purpose でゾーン冗長と柔軟なメモリ設定が一般提供。Always On 可用性グループを扱う MI link も一般提供となります。Azure SQL Database エンジンをローカルで動かすコンテナーは Preview で、クラウドへの移行前に開発や統合テストを行う用途を対象にします。
- [Dynamics 365・Salesforce 連携](announcements/business-apps.md) Dynamics 365 Sales と ERP apps の Copilot プラグインが一般提供。営業計画、会議準備、案件の優先順位付け、調達などを Copilot の中で進められます。Salesforce in Copilot は Preview、Sales Cloud in Teams は Pilot。Salesforce Data 360 と Fabric 間の Data Federation も一般提供となります。
- [Copilot Autopilot](announcements/copilot-autopilot.md) 利用者から毎回指示を受ける方式を広げ、スレッドのフォロー、定期業務、継続的なプロジェクト作業を担う個人用エージェントを Frontier 向けに展開開始。テナント内に固有の ID、メモリ、ツールを持ち、管理者がアクセスを制限し、エージェント自身の操作として監査できます。
- [Copilot Code・Copilot Managed Runtime](announcements/copilot-code-runtime.md) Copilot Managed Runtime が一般提供となり、Copilot Code、Cowork、Copilot Studio などで作成したアプリを組織の管理下でホストする共通基盤を提供。必要に応じて Fabric のデータベースやストレージを組み合わせます。自然言語でアプリを作る Copilot Code は Frontier で提供中で、12 月に一般提供を予定しています。
- [Microsoft Copilot SDK 2.0](announcements/copilot-sdk.md) Rust ベースのランタイムを採用して一般提供。共有プロセス内で複数セッションを扱い、状態、認証情報、ツール、ファイル、履歴を分離します。セッション単位の ID、ホスト側で定義するツールとポリシー、永続化と再開を組み合わせ、マルチテナントのエージェントアプリを構築します。
- [Copilot Workspaces](announcements/copilot-workspaces.md) Copilot Notebooks を発展させた共有作業空間を Frontier で提供。チームの資料と会話を集約し、Copilot が変更、未解決事項、対応が必要な操作を示します。個人と AI の対話から、人とエージェントが同じ業務の文脈を共有する協働へ範囲を広げます。
- [Microsoft Edge for Business](announcements/edge-for-business.md) ブラウザーの操作手順を Cowork のスキルにする Skills recorder と、固有のエージェント ID を使う管理されたブラウジングを Preview で追加。拡張機能のリスクを把握する Extension safety は一般提供。機密ページの読み取り制御、Sentinel への監査情報連携、Global Secure Access 統合も Preview で拡張します。
- [Fabric HorizonDB・Database Hub](announcements/fabric-databases.md) Microsoft Fabric HorizonDB をサーバーレス PostgreSQL として Preview で発表。OneLake の分析データと業務 DB をつなぎます。複数環境の DB を検出・監視・管理する Database Hub は一般提供、SQL と PostgreSQL の障害や性能を調べる Database agents は Preview で追加します。
- [Fabric IQ](announcements/fabric-iq.md) OneLake のデータ、Power BI セマンティックモデルの指標、オントロジーの業務上の意味をアプリやエージェントへ提供。Copilot の Power BI モデル参照を広げ、Excel、GitHub Copilot、ChatGPT、Claude 向けの機能を発表しました。統合全体の説明と個別機能の提供段階を区別して導入を判断します。
- [Foundry IQ](announcements/foundry-iq.md) 文書間のエンティティと関係をたどる Knowledge graphs と、検索計画を反復する Microsoft-Retriever-1 を Preview で発表。SharePoint のインデックス型ナレッジソースは権限を反映して一般提供となります。Serverless は公式総合ブログで 2026 年 12 月の一般提供を予定しています。
- [MAI モデル・Model router](announcements/mai-models.md) Microsoft-Decision-1.1 が一般提供となり、分類、ルーティング、検証などの構造化された判断を支援。MAI-Code-2 と Code-2-Flash は GitHub で一般提供。画像生成・サイバーセキュリティ・動画生成のモデルや、Foundry の Model router の拡張も発表し、タスクに応じて品質・速度・費用を選ぶ構成を広げます。
- [Codename MDASH](announcements/mdash.md) AI エージェントによるコードセキュリティシステムを対象組織向け Preview で提供。攻撃対象の把握、コード検査、エージェント間での検証、重複排除と可能な範囲での再現を組み合わせます。大規模リポジトリの分割、進捗の可視化、結果の品質とモデル対応を改善します。
- [Microsoft Copilot](announcements/microsoft-copilot.md) Home と Office in Copilot が一般提供となり、Chat、Cowork、Word、Excel、PowerPoint を一つの作業画面に統合。Auto は複雑な依頼を Cowork に引き継ぐ選択肢を提示します。Today はメールや会議から優先事項と次の作業を準備する機能として Private Preview を開始します。
- [Microsoft Defender・Sentinel](announcements/microsoft-defender.md) Integrated SOC の中核機能と、Windows 上の対象ローカル AI エージェントに対する実行時保護が一般提供。統合した監視と防御をエージェントへ広げます。SIEM 全機能、90 日の Defender データ保持、攻撃時に一時的な制御を適用する Vulnerability shielding、ゼロデイ・新興脅威の表示は Preview です。
- [Microsoft Entra](announcements/microsoft-entra.md) ローカルエージェントと Autopilot に Agent ID を適用する機能を Preview で追加。Microsoft MCP Server for Enterprise と Agentic traffic acquisition は一般提供。MCP Firewall、条件付きアクセスのポリシー計画、テナント横断の構成管理、強い本人確認、バックアップ・復旧をそれぞれ Preview で拡張します。
- [Microsoft Foundry](announcements/microsoft-foundry.md) 本番トレース、評価、Agent optimizer、モデルの追加学習を一つの改善サイクルへ接続。会話全体を評価する Multi-turn evaluation、問題を整理する Insights、Agent optimizer が一般提供となります。専門家による注釈と Managed Training・Programmed Training は Preview として展開します。
- [Microsoft Intune](announcements/microsoft-intune.md) 端末上の AI エージェントを検出し、承認されていないエージェントがある端末を非準拠として扱う機能を Preview で追加。Agent 365、Entra 条件付きアクセス、Microsoft Execution Containers、Global Secure Access を組み合わせ、端末・実行環境・通信の境界を管理します。
- [Microsoft IQ](announcements/microsoft-iq.md) Work IQ、Fabric IQ、Foundry IQ、Web IQ を企業コンテキスト管理としてまとめ、組織の知識、データ、手順をエージェントへ供給する基盤を一般提供。Business plugins で業務別の指示と信頼する情報源を再利用し、Foundry の評価・最適化で本番の結果を次の改善につなげます。
- [Microsoft Perception](announcements/microsoft-perception.md) 旧 Project Perception が一般提供。Red・Blue・Green の専門エージェントとプレイブックで調査、防御、リスク削減を支援します。第三者環境の調査や検知の作成も拡張。Web アプリのテストやリスク削減、AI エージェント保護などの追加機能には個別のプレビュー条件があります。
- [Microsoft Purview](announcements/microsoft-purview.md) 機密情報の分類・ラベル付け、Copilot の根拠データとプロンプトの保護、Windows 上の AI エージェントへのデータ保護を Preview で拡張。未ラベルの機密ファイルも参照制御の対象にし、添付ファイルやリンクを含めて情報の扱いを管理する方針です。
- [Rayfin・Fabric apps・Power BI](announcements/rayfin-fabric-apps.md) Rayfin と Fabric apps の一般提供を発表し、DB、認証、バックエンド、企業データを備えるアプリ構築を拡張。OneLake Governance hub の管理や観測機能も組み合わせます。Power BI Pro ユーザーがセマンティックモデルからデータを書き戻せるアプリを作る機能は Preview で提供します。
- [Web IQ](announcements/web-iq.md) 全 Azure 顧客向けに一般提供。Auto と Auto Advanced により複数の Web 情報種別を使った検索や反復検索を簡略化し、Scopes で参照先を制御します。Places と Weather も一般提供、Commerce は Private Preview。モデル内の知識を外部の新しい情報で補う基盤として位置付けています。
- [Windows 365・Windows 365 for Agents](announcements/windows-365.md) Direct Stream の改善と接続の信頼度に応じたリダイレクト制御が一般提供。エージェント向けには常時利用する Cloud PC、オンプレミスへの Agent ID アクセス、Foundry からの接続を段階的に追加します。管理アシスタントと Windows MAM は Preview、GPU の新しい配信機能と Foundry MCP は翌年の Preview を予定します。
- [Windows Server 2028](announcements/windows-server-2028.md) Windows Server 2028 を Preview で発表。Server Core の堅牢化、セキュリティ基準、耐量子暗号、証明書管理、NVMe、ReFS 起動を拡張します。Windows ML、Foundry Local、vLLM などによる企業内 AI 推論も示し、ハイブリッド AI 機能は限られた顧客向けの早期アクセスで展開します。
- [Windows の AI・管理機能](announcements/windows.md) プロセスコンテナーでエージェントの通信、ネットワーク、ID を管理する機能を拡張。Copilot のローカルファイル操作・PC 診断・検索からの利用も Preview で発表しました。Windows Endpoint Security Platform は一般提供となり、端末の基準設定、宣言的管理、アプリ更新や信頼性レポートは個別のプレビュー段階です。
- [Work IQ](announcements/work-iq.md) Microsoft 365 の文脈をエージェントへ供給し、長時間のタスクや他エージェントとの連携へ拡張。Retrieve、業務アプリとの接続、会議中の文脈を強化します。Listen、メモリ、Office 作成・編集、操作承認には個別の提供条件があり、公式の総覧と詳細ブログで記載に差がある項目を確認する必要があります。
