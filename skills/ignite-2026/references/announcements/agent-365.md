# Microsoft Agent 365

エージェントの活動、用途、ツールを管理する機能を拡張。Microsoft 製・Microsoft 基盤上のエージェントの基礎的な利用状況と、プラグイン・スキル管理が一般提供となります。Dynamic Agent Risk、MCP ゲートウェイ連携、ローカル・シャドーエージェント管理は Preview。Action center は 12 月の Private Preview を予定します。

確認日 2026-11-20

## 概要

Agent 365 はエージェントの一覧、利用状況、管理、セキュリティを結び付けます。今回の発表は管理の対象を、プラグイン、スキル、MCP ツール、端末上のエージェントまで広げる内容です。

## 主な発表

- Microsoft 基盤上の対象エージェントについて、ユーザー、活動、セッション、例外率、実行時間などの基礎的な可視性を拡大します。
- 管理センターでプラグインとスキルの利用者・グループを指定。MCP ゲートウェイのツールと依存関係も扱います。
- Dynamic Agent Risk は ID、アクセス、データ、端末、クラウド、ネットワークなどの信号を統合。Action center は所有者が不在のエージェントや非稼働の対象を確認する入口になります。

## 提供状況・注意点

| 機能 | 発表時点の状況 |
| --- | --- |
| 対象の Microsoft エージェントの基礎的な利用状況、プラグイン・スキル管理 | GA |
| 用途分類、Dynamic Agent Risk、ゲートウェイ連携、ローカル管理の拡張 | Preview |
| Action center | 2026 年 12 月に Private Preview 予定 |

基礎的な可視化の拡大と、有料の高度な管理・セキュリティ機能を分けます。第三者エージェントの詳細分析や Defender・Purview の高度な機能などは引き続きライセンス条件があります。Viva Insights の対象の agent insights は Copilot ライセンス 50 件以上の割り当て条件も確認してください。
