# Azure Catalyst

インフラ、アプリ、データの調査から計画・移行・モダナイゼーションまでを Azure と GitHub でつなぐ Azure Catalyst が一般提供。Catalyst agent は旧 Azure Copilot migration agent を引き継ぎます。既存資産の把握とエージェントによる実行を接続し、より詳細な調査や統合移行シナリオを Preview で追加します。

確認日 2026-11-20

## 概要

Azure Catalyst は移行の計画と開発側の変更をつなぐ統合的なモダナイゼーション体験です。既存環境の調査結果を Azure Copilot と GitHub Copilot の実行支援に渡します。

## 主な発表

- Azure Catalyst agent は調査、計画、移行を支援。新しい拡張でアプリ検出、戦略と費用の比較、アプリ・DB・ストレージ・ネットワークの計画と実行を深めます。
- GitHub Copilot の modernization はガバナンスの rulebooks、CLI と IDE の bring-your-own-model 対応を拡張します。
- アプリとデータベースの統合モダナイゼーション、BizTalk から Azure Logic Apps への移行を新しい対象として発表しました。

## 提供状況・注意点

Catalyst と Catalyst agent、rulebooks、CLI・IDE の BYOM は GA。より詳細な検出・比較・実行や、新しい統合移行シナリオは Preview。

移行の自動化を検討する際は、対象資産の対応状況、変更を承認する担当者、切り戻し方法を確認してください。
