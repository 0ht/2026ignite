# Azure Chaos Studio

Workspaces と AKS 拡張が一般提供。可用性ゾーンの停止やデータベースのフェールオーバーなどの障害シナリオを再利用し、アプリの復旧能力を検証します。AKS 拡張は実験実行に必要な権限を減らし、Kubernetes Pod への制御された障害注入を支援します。

確認日 2026-11-20

## 概要

Chaos Studio は意図的に障害を発生させ、アプリが想定どおりに応答・復旧するかを確かめるサービスです。今回、実験の整理と AKS での実施を扱いやすくします。

## 主な発表

- Workspaces は対象リソースをまとめ、ゾーン喪失や DB のフェールオーバーといった再利用可能なシナリオで実験を構成します。
- AKS 拡張は Pod への障害注入に対応し、実験を実行するための権限を減らします。
- 同じ実験を繰り返し、アプリ変更後も回復性を確認する使い方を想定しています。

## 提供状況・注意点

Workspaces と AKS 拡張は GA。実験の対象範囲、停止条件、権限、業務への影響を事前に設定してください。実験の実行と復旧の確認を含む運用設計が必要です。
