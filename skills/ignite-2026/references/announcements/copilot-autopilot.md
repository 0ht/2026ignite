# Copilot Autopilot

利用者から毎回指示を受ける方式を広げ、スレッドのフォロー、定期業務、継続的なプロジェクト作業を担う個人用エージェントを Frontier 向けに展開開始。テナント内に固有の ID、メモリ、ツールを持ち、管理者がアクセスを制限し、エージェント自身の操作として監査できます。

確認日 2026-11-20

## 概要

Autopilot は組織のテナント内で継続して働く個人用エージェントです。依頼を一度処理して終了する使い方に加え、会話の追跡や定期的な作業を引き受けます。

## 主な発表

- Teams のチャネルやグループチャットで本人の Autopilot をメンションし、情報の確認や対応可能な操作を依頼できます。
- 固有の Microsoft Entra Agent ID と担当マネージャーを持ち、サインインと操作をエージェント名義で記録します。
- Work IQ による組織の文脈を使い、管理者はアクセス範囲の設定や停止を行えます。重要な操作で本人に確認する運用を組み込めます。

## 提供状況・注意点

Frontier プログラムで展開開始。利用可否、展開時期、許可する操作はテナントの設定と参加条件を確認してください。継続実行の導入では、所有者、実行範囲、承認が必要な操作、支出上限を先に定義します。
