# Fabric IQ

OneLake のデータ、Power BI セマンティックモデルの指標、オントロジーの業務上の意味をアプリやエージェントへ提供。Copilot の Power BI モデル参照を広げ、Excel、GitHub Copilot、ChatGPT、Claude 向けの機能を発表しました。統合全体の説明と個別機能の提供段階を区別して導入を判断します。

確認日 2026-11-20

## 概要

Fabric IQ はデータの値と、業務で使う指標やエンティティの意味をまとめて供給します。アプリごとに異なる売上定義を作る代わりに、管理されたセマンティックモデルと文脈を再利用する構成です。

## 主な発表

- Microsoft Copilot で Power BI セマンティックモデルを参照します。
- Excel の Edit with Copilot から管理されたモデルへ質問し、Fabric 接続のピボットテーブルを作成する機能を発表。
- GitHub Copilot のオントロジー参照、ChatGPT・Claude のコネクター、Fabric apps 内の対話体験へ利用を広げます。

## 提供状況・注意点

Copilot の Power BI セマンティックモデル参照は GA。Excel、GitHub Copilot のオントロジー、ChatGPT・Claude コネクターは Preview と記載しています。

Book of News の冒頭は複数の統合をまとめて GA と説明しますが、同じ節の個別機能には Preview が含まれます。Microsoft IQ 総合ブログも Fabric data agents の Copilot 統合は GA 予定、Fabric apps への対話体験は Preview としています。機能ごとの条件を優先して確認してください。
