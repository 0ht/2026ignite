# Microsoft Copilot

Home と Office in Copilot が一般提供となり、Chat、Cowork、Word、Excel、PowerPoint を一つの作業画面に統合。Auto は複雑な依頼を Cowork に引き継ぐ選択肢を提示します。Today はメールや会議から優先事項と次の作業を準備する機能として Private Preview を開始します。

確認日 2026-11-20

## 概要

Copilot は質問への回答と、複数ステップの業務を任せる操作を Home に集約。会話から Office ファイルの作成・編集・共同作業までを同じ画面で進める構成になりました。

## 主な発表

- Home は Chat と Cowork の共通の入口です。Auto が複雑な依頼に Cowork を推奨し、利用者が選択すると文脈を引き継ぎます。
- Office in Copilot は Word、Excel、PowerPoint の編集と共同作業を統合。ファイルは OneDrive に保存し、既存の権限、秘密度ラベル、コンプライアンス制御を継承します。
- Today はメール、予定、チャット、会議から優先事項をまとめ、メール下書きや予定変更案を準備します。朝の Today Brief と日中更新の Today Feed に分かれます。

## 提供状況・注意点

| 機能 | 発表時点の状況 |
| --- | --- |
| Home、Office in Copilot、Chat から Cowork への推奨 | GA |
| Cowork で Microsoft-Decision-1.1 による処理量選択 | Frontier |
| Today | Frontier 経由の Private Preview |
| Cowork からの宣言型エージェント利用 | Frontier 経由の Private Preview |

Today Brief は Microsoft 365 Copilot ライセンスに含まれ、Today Feed の継続更新には Copilot credits が必要とされています。Office の一般提供と Today の参加条件を分けて確認してください。
