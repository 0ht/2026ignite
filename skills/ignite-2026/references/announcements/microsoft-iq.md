# Microsoft IQ

Work IQ、Fabric IQ、Foundry IQ、Web IQ を企業コンテキスト管理としてまとめ、組織の知識、データ、手順をエージェントへ供給する基盤を一般提供。Business plugins で業務別の指示と信頼する情報源を再利用し、Foundry の評価・最適化で本番の結果を次の改善につなげます。

確認日 2026-11-20

## 概要

Microsoft IQ は、モデルの外側にある組織固有の知識や業務手順を管理するプラットフォームです。コンテキストを供給する四つの IQ と、実運用から改善する Foundry を組み合わせます。

## 主な発表

- Work IQ は人の業務、Fabric IQ は業務データと指標、Foundry IQ は文書などの知識、Web IQ は外部の最新情報を担います。
- Business plugins は業務別に使うコンテキスト、ツール、スキル、正しい情報源を定義。組織・部門・プロジェクトの階層で継承し、専門家の知見を再利用します。
- 継続的改善では評価と本番の観測結果をつなぎ、エージェントの設定変更やモデルの追加学習を検討します。

## 提供状況・注意点

Microsoft IQ は GA。既存製品を組み合わせる構成で、新しい SKU・サブスクリプションを追加する発表としては位置付けていません。構成サービスの料金やライセンスは引き続き確認が必要です。

Business plugins の管理された階層的なガイダンスは Frontier で提供。各 IQ の追加機能にはプレビューや将来予定が含まれるため、プラットフォーム全体の GA と分けて判断します。
