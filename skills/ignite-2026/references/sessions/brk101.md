# BRK101: Microsoft Ignite 101: Navigate, Connect & Maximize Your Experience

Microsoft Ignite の公式アプリ、会場・配信コンテンツの使い分け、学習・認定資格・交流の機会を、登壇者によるアプリのデモを交えて案内します。

確認日 2026-11-24

## 概要

Rick Claus と Sonia Cuff が、Microsoft Ignite 2026 の参加者向けに、会場の歩き方、セッションの探し方、学習機会の選び方、専門家や他の参加者との交流方法を説明します。公式イベントアプリのデモを交え、会場参加者が限られた時間を使って学び、つながるための実践的な案内を行う内容です。

## セッションの内容

### イベント情報と公式アプリ

登壇者は、Ignite の Web サイトで配信番組やおすすめセッションを確認し、モバイルでは Microsoft Events アプリを使う流れを紹介します。アプリのデモでは、セッションの検索・おすすめ表示・予定への追加、会場内の行き方、ガイド、シャトル情報、日ごとの食事メニュー、セキュリティ案内を取り上げています。会場間の移動時間は、説明によればセキュリティ待ち時間に応じて更新されます。

また、イベント情報を答えるチャットボット「Event Assistant」も実演されます。登壇者の説明では、イベントの FAQ や各種案内を参照し、参加者が共有に同意したプロフィール・予定などをおすすめに活用する仕組みです。Web サイト側の配信番組（Broadcast）は、基調講演後のインタビューやパネル、デモなどをオンライン参加者向けに配信し、一部は後日オンデマンドで見られると紹介されています。

### 学習コンテンツの選び方

セッションでは、形式ごとの所要時間と参加方法、後日視聴の可否が説明されます。

| 形式 | 講演で案内された内容 |
| --- | --- |
| Breakout | 45分。技術的な内容や実例、デモなどを扱い、ライブ配信と録画の対象。 |
| Hands-on lab | 75分。事前予約制で、満席の場合も開始直前の待機列から空席に入れる場合がある。会場限定で、録画・ライブ配信はなし。 |
| Theater | 25分。Hub のオープンな会場で実施。録画はオンデマンド公開されるが、ライブ配信はなく、録画には登壇者映像が含まれない。 |
| Lightning Talk | 15分の短い講演。講演では会場参加限定として案内され、録画の説明はありません。 |

参加者は、後日視聴できない会場限定の形式を優先するか、興味のある講演を後から見直せる形式にするかを考え、予定を詰め込み過ぎず休憩も確保するよう勧められます。認定資格については、参加者は事前登録のうえ、会場で Microsoft または GitHub の試験を1つ無料で受けられると説明されています。さらに、ラボや講演、パートナー体験などをめぐるイベント内の「Skills Quest」と、終了後の学習に向けた AI Skilling Navigator も紹介されます。

### 人との交流と参加後の振り返り

MVP のテーブルトークや Microsoft の専門家、パートナーのブースを活用し、質問を持って相談すること、他の参加者に毎日話しかけて知見を交換することが勧められます。LinkedIn の情報共有を選択した参加者は、バッジの QR コードでつながる方法も案内されます。

イベント終了時には、Event Assistant にエグゼクティブ向けのブリーフィング／参加報告を依頼できる例が示されます。講演によれば、本人が共有に同意した参加セッションや学び、交流したパートナーの情報をもとに、PowerPoint 形式の報告を作成します。各セッションの QR コードからフィードバックを送るよう呼びかけて締めくくります。
