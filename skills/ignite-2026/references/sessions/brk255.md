## 概要

Foundry Local を使い、端末上で動く AI アプリやエージェントの構築、推論、性能最適化を紹介します。

## 内容の要約

「クラウドだけでなく、端末やオンプレミスでも使える unmetered intelligence」を掲げ、Foundry Local を Microsoft Foundry のモデル／ツール／エージェント基盤を端末・自社管理環境で動かすクロスプラットフォームのスタックとして説明します。クラウド、オンプレミスのクラスターやサーバー、PC・Mac・Linux 端末では実行できるモデル規模が異なるため、用途とハードウェアに適したモデルを選ぶという考え方が示されます。

アーキテクチャでは、アプリに組み込む SDK（JavaScript、Python、C/C++、C#、Java、Rust など）、ネイティブ ABI、ONNX Runtime、Foundry Catalog を使ったモデル取得、Windows の WinML による実行プロバイダーの取得・登録を説明します。アプリからモデルのダウンロード、ロード、推論を扱い、対応 GPU 等がなければ CPU をフォールバックとして利用します。REST の OpenAI 互換エンドポイントや CLI は、複数言語・プロセスとの接続や開発時の試行にも使えます。チャットに限らず、音声文字起こし、埋め込み、ランキング、判断モデルなどのモダリティも扱い、独自モデルを ONNX に変換して持ち込む方法にも触れます。

デモでは、Foundry Local を組み込んだ GitHub Copilot の音声入力を端末上で実行し、Nemotron 系文字起こしモデルを使う例を示します。別のハイブリッド・ルーティング例では、小型モデルでリポジトリを調べ、タスクの大きさ・秘密情報の有無・深い推論の必要性を見て、端末内で処理するかクラウドへ回すかを判断します。顧客事例の映像では、医療現場のオフライン翻訳、会議や資料の文脈を扱うアプリ、機密 PDF の端末内解析、停電時の電力復旧支援、ローカル文字起こしが紹介されます。

後半の焦点はローカルのコーディングエージェントです。長いコンテキストを使った反復的な推論・ツール呼び出しに対応するため、DFlash 2 speculative decoding、prefill cache、カーネル／グラフ最適化、KV-cache 量子化、GPU と CPU の協調、並列リクエストのスケジューリングを紹介します。RTX Spark 上の Qwen3.8-27B などのデモに加え、24 GB GPU で最大10万トークンのコンテキストを扱う構成や、モデル最適化のベンチマーク結果を示します。GitHub Copilot のデモでは端末上のモデルでゲーム生成や複数ターンのコーディング作業を行い、ツール呼び出しを経て Pull Request を作成します。

## 提供状況

講演では Foundry Local の SDK／CLI や対応環境を紹介する一方、Java SDK は preview、GitHub Copilot アプリに組み込まれた Foundry Local のコーディング用モデルプロバイダーは「preview experience」としてデモされています。最適化済みモデルを Copilot Fusion に追加すること、AMD GPU と macOS への対応は今後の予定として説明されました。実演内容を一般提供済みと解釈せず、各機能の最新状況は資料・公式情報で確認してください。
