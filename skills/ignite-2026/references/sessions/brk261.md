## 概要

アカウント、トリガー、記憶、スキルを備えた継続的なエージェントで、繰り返し発生する業務を支援する方法を示します。

## 内容の要約

Evan Lew と Matt Hidinger は、ユーザーが Copilot に情報を貼り付けて回答を人手で転記する使い方から、チームの共有業務を継続して担う「デジタルチームメイト」へエージェントを進化させる構想を示しました。個人の生産性を支援する Autopilot と、組織の共有プロセスを担い、作った組織に管理される Copilot Studio エージェントを区別しています。必要な要素を、チームの一員として働くためのアカウント、標準手順や外部システムを扱うスキル／ツール、過去の業務を引き継ぐメモリとして説明しました。

### 「Go for Launch」デモ

- 製品ローンチの調整を行うエージェント「Go for Launch」に、Dataverse 上の記録、Teams チャネル、メール、Word、SharePoint を組み合わせました。定期トリガーが日々の状況・期限超過をチャネルに投稿し、エージェントはローンチのレビュー資料を作成し、人に確認が必要な箇所を文書のコメントで示します。指示を受けて文書だけでなく記録やチームへの連絡も更新する例を説明しました。
- Agent Account のデモでは、エージェントに Entra ID の独自アカウント、メールボックス、予定表、プレゼンスを与え、Teams のチャネル／グループ会話、Outlook、Word・Excel・PowerPoint から利用する様子を紹介しました。Dataverse の認証はエージェント自身のアカウントを利用し、従来の作成者共有資格情報や、利用者ごとの接続と比較しています。
- 管理者向けには Power Platform の環境アクセス権と Dataverse のセキュリティロール、Microsoft 365 管理センターのエージェントマップ、共有範囲、ツール・利用状況の確認、Purview の DLP／機密ラベル、Entra Conditional Access を示しました。クレジットの会話別・エージェント別可視化、エージェント／環境単位の上限・アラート・停止も説明しています。

### スキル、コンピューター操作、メモリ

- **スキルとプラグイン**：チームの標準手順書をスキルにして複数のエージェントや Office から再利用する考え方を紹介しました。プラグインはスキル、コネクタ、ツール、知識をまとめて見つける仕組みとして説明されています。
- **コンピューター操作と MCP アプリ**：API がない Web フォームをクラウドブラウザーで操作する例、デスクトップ購買アプリで発注内容を入力する例、MCP アプリから対話型カレンダーを回答に埋め込む例が取り上げられました。カレンダー UI のライブ表示は字幕上、デモ中に読み込めず、登壇者は再試行後も成功を確認できませんでした。従って UI の動作はセッション中に実演できたものとして扱っていません。
- **メモリ**：全体で使う業務コンテキスト、個人の好み、記録すべき出来事、作業方法の改善をエージェントが保存し、利用者が内容を確認・削除できる画面を示しました。Woodgrove Bank の顧客証言利用申請を過去の記録から回答する例や、共有リンクの権限、保存先の指定を記憶する例がありました。
- **顧客事例**：Lumen の Brand Buddy はブランド提出物を確認し、問題箇所を示す PDF を返す取り組みとして紹介されました。字幕では顧客デモの映像が再生されず、登壇者・顧客の説明に基づく範囲に留まります。

### 提供状況・時期

- スライドはトリガー、スキル、ツール、メモリを「利用可能」とし、Agent Account と Teams／Outlook／Office での利用、および同アカウントへのガバナンスを「Frontier Public・2026年12月」と記載しています。
- メモリ管理と共有スキルは「利用可能／パブリックプレビュー」、コンピューター操作と MCP アプリは「2026年11月のパブリックプレビュー」とされています。プラグインのレジストリも11月予定です。
- コンピューター操作は、公衆向け Web サイトが11月、Key Vault 資格情報によるサインイン済みサイトと Windows 365 for Agents のクラウド PC が12月の予定として示されています。これはスライド上の発表時点の予定であり、公開済みになったことを本記事では別途確認していません。
