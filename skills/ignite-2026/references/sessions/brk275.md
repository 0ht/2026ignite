# BRK275: What should you build when you can build anything?

ゲームや学習ツールのデモを通じて、AI 支援開発の創造的な使い方と、開発者が学び続ける重要性を紹介します。

## 概要

AI に一度指示して既存作品に似たものを作るだけではなく、人の目的・専門性・学習を使って独自の道具を作ることをテーマにしたデモ中心の講演です。

- Anthony は OpenRCT2 にローカル実行の小規模言語モデルを組み込み、来園者の内心を生成。さらに2種類の意思決定モデルを服の色で分けて比較し、来園者の幸福度を高める調整を実験しました。ゲーム資産は正規所有が必要で、商品化の話ではありません。
- Katie の Tone Mirror は中国語の単音節の声調を練習する Web アプリ。録音とネイティブ話者の参照音声を比較し、YIN アルゴリズムによる音高とルールで判定します。話者の音域の校正や、第3声のきしみ声を誤って不良録音とする問題を改善しました。
- Tone Mirror は一発生成ではなく、ネイティブ話者による確認と Copilot を使った調査・修正を重ね、約1.5〜2週間かかったと説明。単音節の練習という範囲であり、発音全般の完全な評価を主張していません。
- Scott の GPU Task Man は GPU 上のプロセス、モデル、消費電力などを表示するテキスト UI。本人の Windows ARM 環境向けに作り、他の GPU への対応はコミュニティと進めている事例です。
