## 概要

Copilot Memory、Dreaming、コード検索、Agentic Search を組み合わせ、開発の履歴を次の作業に活かす自己改善の仕組みを紹介する。

## 内容の要点

- **仕組み**：Memory はユーザーの好みやリポジトリの慣行をセッション間で利用し、Dreaming は背景処理で過去の作業から記憶やレビューの指示を整理する。デモでは人が繰り返し指摘していた変更履歴や評価に関する慣行が、Copilot Code Review の指摘に反映された。
- **検索とデモ**：語句で探す lexical search と意味で探す semantic search を組み合わせる。Agentic Search は PR・issue・commit・コード、任意の Copilot セッションを横断し、日次更新の SQLite キャッシュと最新の GitHub API 情報を使う。例では2週間の PR とセッションから失敗や作業上の障害を分析した。
- **評価と制約**：登壇者の8,000超のセッションのサンプルでは、Memory が役立ったと判断されたものは22%。回答順や優先順位は実行ごとに変わり得るため、人が判断し、変更後に再計測する必要がある。キャッシュは日次更新であり、常に最新ではない。
- **発表当時の状態**：Memory は有料 Copilot プラン、Dreaming は public preview、code search は agent クライアントで利用可能と説明。Agentic Search は参加登録して試すプレビューとして紹介され、組織管理者がアクセス対象のユーザーとリポジトリを設定する。
