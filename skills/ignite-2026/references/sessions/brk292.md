## 概要

Azure Boards、Repos、Pipelines を使い続けながら GitHub Copilot や MCP を連携し、作業項目からコード変更につなげます。

## セッションの内容

Azure DevOps のリポジトリを移行せずに Copilot を使う方法と、GitHub に移行する場合も Azure Boards や Pipelines を維持する方法を紹介します。開発ツールから作業項目を取得してコードを修正する例に加え、レビュー、セキュリティ警告の修正、段階的なリポジトリ移行を取り上げています。

### MCP と Cowork で作業項目を活用

VS Code の Copilot から Azure DevOps MCP サーバーを呼び出し、条件に合うバグを検索して再現手順を取得し、修正とテストにつなげる流れを実演しました。リモート MCP サーバーは発表時点で一般提供されており、ローカル版とともに各種 Copilot クライアントから利用できます。

Microsoft Copilot Cowork の Azure DevOps プラグインでは、Teams の会話を基にユーザーストーリーを作成し、既存の機能項目を親として関連付け、会話へのリンクを残す例を紹介しました。GitHub Copilot app の自動化では、親項目のない作業項目をクエリで見つけ、指定したルールに従って関連付けます。

### Copilot app、レビューとセキュリティ

GitHub Copilot app の Azure DevOps 連携は発表時点で**パブリックプレビュー**です。Azure Repos のプルリクエストをアプリ内で確認し、レビューコメントへの対応や Agent merge を利用するデモを示しました。作業項目の取得を伴うデモでは MCP サーバーの追加設定が必要で、アプリから作業項目を直接選んでセッションを開始する機能は今後の予定として説明されています。

Azure Repos 向け Copilot Code Review は**一般提供**と発表されました。組織・プロジェクト・リポジトリで設定し、ブランチポリシーによるレビューの自動要求や、指摘の適用とコメント解決を実演しています。発表者は、Copilot ライセンスを別途必要とせず Azure サブスクリプションに課金されると説明しました。

GitHub Advanced Security for Azure DevOps の Copilot Autofix は**パブリックプレビュー**です。コードスキャンや依存関係の警告を対象に修正案を生成し、プルリクエストで確認する流れを示しました。複数警告の一括選択は今後の予定です。

### リポジトリの移行

Enterprise Live Migrations は、Azure DevOps の Git リポジトリを継続的に同期し、短い切り替え時間で GitHub に移行する仕組みとして紹介されました。発表時点で一般提供され、移行先にはデータレジデンシー付き GitHub Enterprise Cloud が必要と説明されています。
