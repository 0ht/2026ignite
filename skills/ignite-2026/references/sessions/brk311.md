## 概要

Web IQ の検索範囲、セキュリティ、ガバナンスを説明し、企業が公開 Web を根拠とするエージェントを構築した事例を紹介します。

## セッションの内容

Web IQ を既存の企業システムに組み込み、公開 Web の最新情報をエージェントや自動化処理に渡す方法を紹介します。Web IQ は根拠を取得し、回答の生成と業務上の判断は呼び出し側が担当する構成です。

### 検索範囲とデータの扱い

Web、ニュース、画像、動画、場所、指定 URL の取得などの個別エンドポイントと、情報源を自動選択する Auto を説明しました。Passages はページ全体ではなく質問に関連する部分を返し、タイトル、URL、取得時刻を根拠として利用できます。

Scopes は URL、ドメイン、パスなどで検索対象を含めたり除外したりする機能です。Zero Query Logging を有効にするとサービスログへのクエリ記録が抑制されますが、発表者は不要な機密情報を検索に送らない設計や、アプリ側のログ管理も必要と説明しました。

### National Grid のデモ

National Grid の登壇者は、既存のページ取得・解析の保守負担を説明し、障害対応、セキュリティ勧告、製品の更新準備、古くなったナレッジ記事などへの応用を検討例として挙げました。

実演では Copilot Studio に Web IQ の MCP サーバーを追加し、引用付きの最新情報を取得しました。PowerShell から REST API を呼び出し、Web とニュースの結果をモデルに渡す例も示しています。別の例では、検索が必要かをモデルに判断させてから API を呼び、不要な検索を減らします。
