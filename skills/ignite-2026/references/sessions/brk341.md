## 概要

Microsoft の CISO 組織が Agent 365 を使い、エージェントの発見、リスク評価、インシデント対応を行う経験を共有します。

## セッションの内容

Microsoft の CISO 組織は、社内での運用経験を製品に反映する Customer Zero の立場から、エージェントの可視化、リスク評価、封じ込めを紹介します。発表時点で社内のエージェントは 100 万を超え、手動で一つずつ審査する運用は難しいと説明しました。

### 数だけでなく到達範囲と取り消しやすさを見る

所有者、用途、ID、データ、ツール、利用者の関係を把握します。自律性、操作の範囲、データの機密性、権限、信頼できない入力、影響範囲を評価し、特に元に戻しにくい操作には強い管理を求めます。

Microsoft Digital は所有者やライフサイクル、費用を管理し、CISO 組織はリスクとセキュリティ対応を担当します。作成者や業務スポンサーは目的や所有者などの文脈を提供します。

### 検出から封じ込めまで

デモでは Agent 365 からローカルエージェントのインスタンスと関連インシデントを確認し、Entra、Intune、ネットワークの制御を適用しました。別のシナリオでは、IT 管理者が高リスクのエージェントを SOC に引き継ぎ、Defender のアラートを調査します。共通の MCP サーバーを使う他のエージェントも検索し、影響範囲を広げて確認しました。

事前に所有者、権限、承認条件を定め、異常時はエージェントの停止、アクセスの取り消し、ネットワーク制限などを使い分けます。利用可能な制御と停止までの時間はプラットフォームごとに異なるため、事前の検証と担当者の明確化が必要です。
