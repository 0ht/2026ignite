## 概要

Agent 365 でエージェントの所有者、権限、ツール利用、ライフサイクルを一元的に管理する実例を紹介します。

## セッションの内容

### LG U+ のガバナンス

LG U+ は Microsoft テナントだけで 2 万以上のエージェントが作られ、複数クラウドや SaaS にも分散している状況を紹介しました。同社の「Zero Shadow」は、登録・固有の ID・明確な所有者を運用開始の条件とし、インベントリ、観測、審査と証跡を柱としています。

Microsoft との 17 週間の共同開発では 10 プラットフォームと 23 のシナリオを対象に検証しました。Microsoft 製以外のプラットフォームでは、コネクタや認証・テレメトリの追加など、顧客側の実装が必要です。登録だけでアクセス制御が完成するわけではなく、モデルの外で利用者とエージェントの ID に基づき制御することを重視しています。

### Action Center とツールの管理

Action Center のデモでは、所有者不在や 90 日以上未使用のエージェントを優先度付きで確認し、除外対象の指定、ブロックや独自の自動化、操作履歴の確認を示しました。Entra ID を持つ対象についてはアクティビティ情報と操作を Entra と同期します。発表時点では 2026 年 12 月中旬にプレビュー予定と説明されています。

ツールレジストリではプラグイン、スキル、MCP サーバーと依存関係を調べ、サーバー全体や個別の操作を制御する例を紹介しました。MCP の利用状況はパブリックプレビュー、GitHub リポジトリ接続はプライベートプレビュー、ツールの偽装や隠れた指示などの評価は Ignite 後のプライベートプレビュー予定です。

### ID と責任の継続管理

Entra ID Governance のアクセスパッケージで API 権限をまとめ、スポンサーによる申請、承認、有効期限を設定する例を説明しました。所有者の異動や未使用に応じたスポンサーの再割り当てや ID の無効化に加え、Purview の分類とラベル、Defender のローカルエージェント検出を組み合わせます。業務上のスポンサーとデータ・アプリの所有者も、権限と例外の判断に参加することが重要です。
