# BRK373: Build AI-ready apps on Azure SQL with GitHub Copilot in VS Code

VS Code の SQL 拡張と GitHub Copilot を使い、Azure SQL のスキーマ、ベクトル検索、RAG、データ API を構築します。

## 概要

VS Code の SQL 拡張と GitHub Copilot を使い、Azure SQL のスキーマ、ベクトル検索、RAG、データ API を構築します。

## セッションの内容

登壇者は、データベースを持たない React 製サポート案件管理アプリを題材に、VS Code から Azure SQL を組み込み、ナレッジベースを根拠にサポート返信案を作るところまでをライブデモしました。MSSQL 拡張と GitHub Copilot を中心に、作業を一つの開発環境で進める流れです。

まず、Azure SQL Database と同じエンジンを使うローカルコンテナーを起動し、PRD（要件文書）と SQL Agent Skills を Copilot に参照させて、テーブル、列、外部キーを含むスキーマ案を生成します。生成結果は開発者が確認してから適用する手順でした。拡張機能のデータベース接続ツールにより、Copilot はスキーマ情報を使って SQL を組み立てられますが、実行できる操作やデータへのアクセスは接続ユーザーの権限に従い、クエリ実行前には確認を挟む、と説明しています。

次に、Data API Builder でデータベースのスキーマから API を構成し、デモでは読み取り専用の REST エンドポイントを生成・テストして、アプリのハードコードされたサンプルデータを実データに置き換えました。後半は RAG の実装です。ナレッジ記事と問い合わせ文を同じ埋め込みモデルでベクトル化し、Azure SQL のベクトル距離関数で意味的に近い記事を検索します。検索結果と問い合わせを生成モデルに渡して返信案を作り、参照した記事を示して担当者が確認・送信する設計です。関連度が十分でないときは回答を捏造せず、該当記事がないと担当者に返す例も示しました。埋め込み生成は Azure OpenAI を使う構成のほか、ローカルの Ollama を使う選択肢にも触れています。

締めくくりでは、ローカル環境から Azure SQL へのデプロイを実演し、接続先を切り替えてクラウド側で動かす流れを紹介しました。このデプロイ機能は収録時点のプレビューとして、無料ティアを対象に説明されています。中心的な教訓は、Copilot にスキーマだけでなく PRD、リポジトリ、チームの指示、ドメイン固有の Skills も渡して、生成物を人が検証することです。
