# BRK376: Agentic CRM: Accelerate revenue and pipeline with agentic sales

Dynamics 365 Sales と Copilot、エージェントを組み合わせ、営業記録や商談プロセスを支援する CRM の活用を紹介します。

## 概要

Dynamics 365 Sales と Copilot、エージェントを組み合わせ、営業記録や商談プロセスを支援する CRM の活用を紹介します。

## セッションの内容

このセッションの主張は、CRM を営業担当者が後から手入力する「記録システム」から、メール、会議、通話、チャットなど既に生じている信号を取り込み、営業担当者の作業場所で次の行動を支える「行動の仕組み」へ変えることです。Dynamics 365 Sales、Microsoft 365 Copilot、Teams、Outlook をつなぎ、データの更新と営業支援をワークフロー内で行う構想を示しました。

Microsoft のデモでは、Copilot の日次ブリーフィングと顧客・商談情報を基に、顧客向けの一枚資料やメール案、会議準備の要点を作成します。会議後には音声でメモを伝え、連絡先・企業・商談レコードを更新する案を確認して保存し、過去の会議から提案された CRM 更新も担当者がレビューして反映しました。全自動で無確認に書き込む実演ではなく、提案を人が確認する流れです。セッションでは、Copilot は会話や既存システムのシグナルをコンテキストとして使い、Sales Development Agent のように自律的に顧客へ連絡するものまで、支援の度合いを段階的に選べると説明しています。

顧客事例の一つである Softcat は、25年使った見積・受注中心の旧基盤から Dynamics 365 へ移行し、Outlook や Teams など担当者が日常的に使う場所へ CRM を持ち込む方針を紹介しました。見積書を取り込むエージェントは、販売代理店・仕入先の文書を CRM に登録し、担当者が確認できる形にする構想です。約4,000件の見積と1日233時間の作業量を背景に、見積時間を50%以上削減できる可能性を目標として挙げましたが、これは達成済みの測定値ではありません。Teams 内の「Customer Central」アシスタントによる自然言語での顧客・商談作成も紹介し、現場担当者がエージェント案を共有する文化づくりに触れました。Softcat はまだ取り組みの初期段階だと明言しています。

Adobe の事例では、営業が手をかけにくい北米の中小企業約6,000社を対象に、Sales Development Agent で個別メールを送り、返信への対応、リードの選別、適切な段階での人間の営業担当への引き継ぎを試しました。エージェントごとにメールボックスと会話履歴があり、管理者が対話で指示や送信スケジュールを調整し、Excel のリストからキャンペーンを始める例も説明されました。Adobe は直近4回のキャンペーンで約4,500件に連絡し、返信率20～35%、人間への引き継ぎ約15%と報告しています。数値の厳密な内訳は公開されず、同社の発表値です。登壇者は、小規模な対象とメッセージから始め、初期送信を確認し、反応を見て改善するよう勧めました。

将来構想としては、営業データと他の顧客シグナルからのインサイト、ケース管理、学習・能力開発との連携を挙げ、別の発表機能をプレビュー予定として紹介しました。また、Sales Development Agent はセッション中に「まもなくパブリックプレビュー」と述べられています。したがって、これらの紹介は製品の現時点での提供可否を示すものではありません。企業データの共有には Work IQ の統合を通じたアクセス制御、管理、セキュリティ、コンプライアンスが重要だという点も強調されました。
