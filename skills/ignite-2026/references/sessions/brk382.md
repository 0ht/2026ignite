## 概要

Power Platform と Copilot Managed Runtime の環境、アプリのライフサイクル、セキュリティ、監視を企業規模で管理します。

## セッションの内容

### Novartis の市民開発者支援

Novartis は、Power Platform の初期段階では既定環境と Microsoft 365 向けのデータ損失防止ポリシーを使い、より広い業務システムへの接続が必要なソリューションは専門チームの支援を受けて本番化してきたと説明しました。Copilot Studio の利用者拡大に対しては、学習プログラム、専門家による支援、Viva Engage のコミュニティを整備しています。登壇者によると、約500人が市民開発者プログラムに参加し、6,000人が AI・データ基礎研修を受講しました。スライドでは市民開発者プログラムで公開したエージェントを218件としています。

放置・孤立したエージェントが増えることを前提に、所有者が定期的に資産を確認するライフサイクル管理を行い、利用されなくなったものを整理します。ガバナンスは、作成を阻止するより安全な作り方を容易にし、現場の利用者に近いところで支援することが重要だと述べています。

### Power Platform の「Green Zone」

環境ルーティングで開発者を共有の既定環境から個人用環境へ誘導し、環境グループでまとめて管理します。高度なコネクターポリシーでは、グループごとの利用可能なコネクターに加え、SQL コネクターの操作や認証方式などを制限できます。従来の DLP ポリシーから段階的に移行する設定も紹介されました。

管理者は作成開始時の案内、利用規約や連絡先、ポリシーで制限された機能の表示を設定でき、メーカーにはブロック理由や解除方法が示されます。管理センターの資産インベントリと利用状況から、所有者、接続先、利用頻度を確認して、方針を調整する流れです。

### Copilot Managed Runtime の統制

Copilot Managed Runtime は Power Platform の外で作られたアプリも含め、Microsoft や外部の開発ツールから作成したアプリを管理・実行する基盤として説明されました。登壇者は、セッション時点で一般提供開始と案内しています。管理者向けの制御面は Microsoft 365 管理センターで、アプリのインベントリ、所有者・依存関係、利用状況、健全性、コストを確認し、必要に応じてアプリを停止・ブロックできます。

既定の環境グループに用意された「Green Zone」は、初期状態から有効で、利用可能なコネクターや共有先を制限します。Content Security Policy によりアプリ実行時の外部接続も制御し、管理ポリシーは Managed Runtime Host が各リクエストで適用します。MCP サーバーのガバナンスも統制対象に含むとしています。

### 本番運用、費用、管理拡張

Managed Host は Entra ID 認証、Purview の操作ログ、ポリシー適用、運用状態の計測を担います。開発・テスト・本番の環境を分け、Git やパイプラインによる変更管理と品質ゲートを通して、本番の継続性を保つ方法を説明しました。Monitor はアプリ、エージェント、フローの健全性を監視し、発表時点では劣化を1時間以内に検知するアラートやイベント通知、データ出力がプレビューとして紹介されました。

費用面では、ユーザー単位のサブスクリプションと、利用量に応じた Copilot クレジットを区別し、メーカー・管理者が消費量を確認する機能を紹介しました。さらに、Power Platform の管理 API、SDK、PAC CLI、Admin コネクター、Copilot Cowork 用プラグインを使い、管理作業やレポートを自動化する例をデモしました。
