# OD1930: Agent 365: Governing agent access to Microsoft 365 content

Agent 365 で Microsoft 365 のコンテンツに対するエージェントのアクセスを把握し、統制する方法を説明します。

確認日 2026-11-24

## 概要

Agent 365 で Microsoft 365 のコンテンツに対するエージェントのアクセスを把握し、統制する方法を説明します。

## セッションの内容

- **観察すべき4つの問い**：どこでエージェントの利用が集中しているか、機密性の高いコンテンツを利用しているか、読むだけか作成・更新もしているか、誰がアクセスを判断すべきかを挙げた。過剰共有と過度な制限の両方を避けることが目的となる。
- **アクセスのヒートマップ**：SharePoint 管理センターの Agent Governance でレポートを生成し、エージェントの種類と事業グループ、または秘密度別に、アクセスされたサイト・OneDrive・Teams の分布を確認する。例では約2,000のエージェントが24,000超のサイトやアカウントなどにアクセスしていた。
- **調査から対応へ**：銀行部門の Copilot エージェントを掘り下げ、サイトの機密性と読み取り・作成・更新を確認する。サイト別・エージェント別の詳細や所有者を確認し、コンテンツの検出制限や指定グループへのアクセス制限につなげる。
- **ブループリント単位のガードレール**：サイトとエージェントを個別に処理する代わりに、エージェントのひな型であるブループリントに設定し、既存・将来の対象エージェントに適用する。Autopilot の共有範囲、組織外共有の禁止、特定サイトへのアクセス禁止、コンテンツ検出の制限が紹介された。
- **責任分担と状態**：管理者が基本方針を定め、エージェントの管理者やコンテンツ所有者が調整に関わる。発表時、ヒートマップはパブリックプレビュー、コンテンツのガードレールは一般提供と説明された。
