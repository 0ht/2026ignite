# OD1931: Agent Rewind: When agents go off script

エージェントが意図しない動作をした場合の影響を想定し、Microsoft 365 のバックアップとサイバー回復を検討します。

確認日 2026-11-24

## 概要

エージェントが意図しない動作をした場合の影響を想定し、Microsoft 365 のバックアップとサイバー回復を検討します。

## セッションの内容

- **Agent Rewind の調査と復旧**：Microsoft 365 Governance Agent に依頼し、疑わしいエージェントを選んで7日間の活動を調べる。デモでは変更が急増した時点を特定し、サイトやコラボレーションの所有者と望ましくない変更を確認したうえで、正常な時点を指定して影響を受けた対象を巻き戻す流れを説明した。
- **初期対応範囲に注意**：Agent Rewind のプライベートプレビュー初期段階は、特定されたエージェントによる SharePoint サイトと OneDrive アカウントの操作が対象。Exchange Online、Teams、Entra、Agent 365 の構成などは将来の拡張として述べられた。重要なサイトやアカウントを先に復旧する prioritized recovery もプライベートプレビューとして紹介された。
- **バックアップの拡充**：Teams チャネルのバックアップはプライベートプレビューで、日次バックアップと30日の復旧期間を説明。チームと関連グループの完全削除に対する保護は未対応とされた。Entra Backup and Recovery Premium の統合はパブリックプレビューで、日次・30日間の復旧と差分レポートを紹介し、完全削除の保護は別途有効化する必要があると説明した。
- **カバレッジと監査**：カスタムポリシーに含まれない SharePoint、OneDrive、Exchange Online を自動で対象にするフルワークロードバックアップはパブリックプレビュー。Backup の操作ログ、コンプライアンスレポート、90日から2年までの復旧期間の選択肢は一般提供として紹介された。
- **データの整理も回復力の一部**：Governance Agent がストレージ消費、版、利用状況、Multi-Geo を分析する例を示した。版の削除は永続的な操作で、人の承認を前提とし、初期段階の実行は SharePoint UI または PowerShell で行うと説明した。非アクティブなファイルのアーカイブ方針も承認後に作成する。
- **運用スキルと容量**：エージェント所有の OneDrive 使用量を調べるスキルはプライベートプレビュー、OneDrive の地域移動を確認・開始・追跡する Multi-Geo Management Skill はパブリックプレビューと紹介された。SharePoint の従量課金ストレージもパブリックプレビューとして、整理・アーカイブ後に必要な容量を追加する選択肢を示した。
